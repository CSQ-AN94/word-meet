# 同词相遇：HTTPS 联机

用户要求不同设备、浏览器、Wi‑Fi 均可加入同一房间。此前 PeerJS 直连方案在跨网络时失败，现替换为服务器同步。

- 保持双人联想玩法、房间码、邀请链接和提交后同时揭晓。
- 两个浏览器分别通过普通 HTTPS 访问房间服务，不使用 WebRTC 或 NAT 穿透。
- 服务器用 D1 原子操作分配两人席位，通过独立随机令牌鉴权，消息按序号轮询并去重。
- 临时断网重试同一条消息，保留本轮内容；新加入产生新对局编号，过滤旧对局消息。
- 网站不要求账号和第三方 Cookie。GitHub Pages 入口及服务器同源入口均使用相同前端。
- 使用真实本地 HTTP 请求和 SQLite，验证没有 PeerJS/WebRTC API 时仍能完成多轮对局、处理房间已满和恢复短暂断网。
- 上线后验证匿名 API、跨来源请求和内置浏览器对局。实际用户的 Safari 与同学设备仍需由他们重新建房验证，不能以同机双标签测试代替。
